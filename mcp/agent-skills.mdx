title: "Agent skill"
---

Install the [Google Maps Data skill](https://github.com/ricciflow-api/gmapscrawl-agent-skills). It uses `search_google_maps` with a REST fallback at `/api/v1/search`.

The skill covers source pages, 20-business responses, retry identifiers, credential handling, and untrusted scraped text. The helper accepts a request document with operation `places.search`, an input object, and client_request_id. It sends the flat input as the REST body.
