---
title: "Availability"
---

G Maps Crawl Online, Extension, REST API, and MCP are officially released. MCP is available on free and paid API plans and uses the API allowance; Online and Extension have separate allowances.

Live search depends on your API plan, credential permissions, source availability, and server capacity. A `capability_unavailable` or capacity error means that search could not be admitted, not that the product is awaiting release. Do not treat tool discovery as proof that a live request succeeded.

The Search API offers business search only. Standalone reviews, photos, asynchronous API exports, and customer webhook endpoints are not part of the Search API. The separate Online scraper supports dashboard jobs. Eligible paid Online plans include CSV, Excel, and JSON exports and email/social enrichment, subject to plan limits and source availability.
