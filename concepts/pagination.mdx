---
title: "Pagination"
---

Send `page` from 1 through 10; the default is 1. Each page is a separate request and returns at most 20 businesses. Keep q and location parameters unchanged when requesting the next page. An empty page is a valid result and uses one request unit; stop when no businesses are returned.

Search results can change between requests. Pages are slices of the retrieved listings, not a guarantee of exhaustive or stable Google Maps coverage. There are no result cursors.
