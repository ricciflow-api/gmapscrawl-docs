---
title: "Pricing and usage"
---

Each successfully completed live search page uses one API request, including an empty page. Accepted work reserves one unit; failed searches release the reservation. Replays of an identical request do not charge again. Test keys use zero units.

| Plan | Monthly price | Included requests | Additional request |
| --- | --- | --- | --- |
| Free | $0 | 20 | Hard cap |
| Basic | $15 | 1,000 | $0.014 |
| Professional | $65 | 5,000 | $0.012 |
| Business | $115 | 10,000 | $0.011 |
| Scale | $365 | 50,000 | $0.009 |
| Scale Plus | $799 | 150,000 | $0.006 |
| Scale Pro | $1,499 | 350,000 | $0.0045 |
| Scale Max | $2,999 | 800,000 | $0.0035 |

Every plan returns up to 20 businesses per request. Allowances reset each monthly billing period. Online and Extension subscriptions are separate. [Current pricing](https://gmapscrawl.com/pricing?tab=api).
