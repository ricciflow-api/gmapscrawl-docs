---
title: "Google Maps Search API"
---

Search Google Maps businesses with one synchronous request. Each response contains up to 20 businesses. Use REST or the single MCP tool `search_google_maps`.

G Maps Crawl Online, Extension, REST API, and MCP are officially released. MCP is available on free and paid API plans and uses your API allowance. Online, Extension, and API have separate allowances and plan limits.

Start with the [quickstart](/quickstart), [API reference](/api-reference/search), or [MCP connection](/mcp/connect).
